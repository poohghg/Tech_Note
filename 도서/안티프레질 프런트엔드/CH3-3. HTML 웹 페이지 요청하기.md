> 웹 서버는 브라우저에 보내듣 HTTP 응답 헤더의 Content-Type필드를 통해 지금 응답하는 데이터가 어떤 타입의 데이터인지 브라우저에게 알려준다.

- Content-Type: text/html 이고 utf-8로 인코딩된 파일이므로 HTML파일로 다뤄서 DOM파싱을 해야하는 데이터이고, 데이터의 바이트를 UTF-8로 디코딩해야 한다는 것을 브라우저에게 알려준다.
- Content-Encoding: br, gzip, deflate 등으로 압축되어 있는 경우에는 브라우저가 압축을 해제해야 한다는 것을 알려준다.
	- br: Brotli 압축 알고리즘으로 압축되어 있다는 것을 알려준다.
	- gzip: Gzip 압축 알고리즘으로 압축되어 있다는 것을 알려준다.
	- deflate: Deflate 압축 알고리즘으로 압축되어 있다는 것을 알려준다.

> 웹 서버가 응답 헤더를 통해 브라우저에 서버와 현재 전송하는 데이터
