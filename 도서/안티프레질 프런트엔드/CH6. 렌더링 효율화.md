> 브라우저는 초당 60 프레임을 목표로 렌더링을 수행한다. 이는 ==1초에 60번 화면==을 새로 그린다는 의미이며, 각 프레임은 약 16.67ms(1000ms / 60) 동안 처리되어야 합니다. 만약 렌더링이 이 시간을 초과하면, 사용자는 화면이 끊기거나 느리게 반응하는 것을 경험하게 된다.

#### 레이어 분리

> 화면에 렌더링해야 하는 요소들에 변경 사항이 생기더라도 브라우저가 항상 모든 렌더링 단계를 다시 수행하지 않는다. 브라우저는 렌더링 과정에서 레이어를 분리하여, 변경된 부분만 다시 렌더링하도록 최적화한다. 예를 들어, 화면의 일부 요소가 변경되었을 때, 브라우저는 해당 요소가 속한 레이어만 다시 그리게 된다. 이를 통해 불필요한 렌더링 작업을 줄이고 성능을 향상시킬 수 있다.

> 만약 특정 레이어의 스타일이나 위치가 변경되어 레이아웃이나 페인트 단계를 다시 수행하게 되더라도 브라우저는 변경에 영향을 받는 해당 레이어에 필요한 연산만을 다시 수행하면 된다. 따라서 하나의 화면을 자주 변경되는, 혹은 함깨 변경되는 요소들로 묶어 하나의 레이어로 분리하면 렌더링 성능이 개선된다.> 

> 성능 좋은 웹 페이지를 만드려면 화면을 사용자에게 의미 있는 단위로 분리하고, 자주 변경되는 요소들을 하나의 레이어로 묶어 렌더링 효율을 높이는 것이 중요하다.
> 예를 들어 시멘틱하게 관련 있는 요소들을 하나의 레이어로 묶어, 해당 레이어에 변경이 발생했을 때만 다시 렌더링하도록 설계하는 것이 좋다. 이렇게 하면 불필요한 렌더링 작업을 줄이고, 사용자 경험을 향상시킬 수 있다.
