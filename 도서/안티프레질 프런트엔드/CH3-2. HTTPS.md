> 웹 서버와 브라우저는 HTTP가 가진 보안상의 취약점을 개선하려고 HTTPS를 사용해 데이터를 주고받도록 한다. HTTPS는 HTTP에 SSL/TLS 프로토콜을 추가하여 데이터를 암호화하고, 서버와 클라이언트 간의 통신을 보호한다. 이를 통해 중간자 공격, 데이터 변조, 도청 등의 보안 위협으로부터 사용자의 데이터를 안전하게 지킬 수 있다.

> HTTPS를 사용하려면 실제로 요청을 보내기 전에 보안 연결을 맺는 과정이 필요하다. 


### HTTP의 문제점

> ==HTTP는 데이터를 암호화하지 않고 평문으로 전송하기 때문에, 데이터가 그대로 노출된상태이다==. 중간자 공격이나 도청 등의 보안 위협에 취약하다. 또한, 데이터 변조가 발생할 수 있으며, 사용자의 개인정보가 유출될 위험이 있다. 이러한 문제점을 해결하기 위해 HTTPS가 등장하였다.

### HTTPS가 데이터를 보호하는 방법

> HTTPS는 HTTP의 보안문제를 해결하기 위해 웹 브라우저와 서버 둘만을 암호화하고 복호화하는 세션 키를 만드는 과정을 거친다. HTTPS에서는 TLS 핸드세이크라는 단계를 먼저 거치게된다. 브라우저와 웹 서버가 서로의 데이터를 암호화, 복호화하는데 사용될 공통된 세션 키를 생성하고 이를 사용하여 서버에 전송할 데이터들을 암호화한 후 요청을 보낸다.

#### 비대칭 키 암호화

> HTTPS는 비대칭 키 암호화를 사용하여 브라우저와 서버 간의 안전한 통신을 보장한다. 비대칭 키 암호화는 공개 키와 개인 키라는 두 개의 키를 사용한다. 공개 키는 누구나 접근할 수 있으며, 데이터를 암호화하는 데 사용된다. 반면, 개인 키는 서버만이 가지고 있으며, 암호화된 데이터를 복호화하는 데 사용된다.
