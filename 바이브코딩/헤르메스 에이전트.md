> 스스로 학습하며 점점 더 유능해지는 자율적인 에이전트 어디에나 설치 할 수 있으며, 다양한 채널을 통해 에이전트에 접근할 수 있다.

> 작업이 끝난뒤 백그라운드에서 대화를 리뷰하고 스스로 스킬을 생성하는 자동화 메커니즘에 더해, 백그라운드 큐레이터가 7일 주기로 라이브러리 전체를 정리해 주는 기능을 제공한다. 또한, 사용자가 직접 스킬을 생성하고 공유할 수 있는 Skills Hub를 제공한다.
### 주요기능

- 폐쇄형 학습 루프: 에이전트가 선별한 정보를 주기적으로 제공하고, 자율적으로 기술을 개발하며, 사용 중에도 기술을 지속적으로 개선한다. 또한, FTS5를 활용한 세션 간 정보 회상 기능과 LLM을 통한 요약 기능도 제공한다. Honcho 방식을 활용한 사용자 모델링이 이루워진다.
- 백엔드 ,CLI, GUI, 웹, 모바일 등 다양한 채널을 통해 에이전트에 접근할 수 있다.
- 병렬 처리 기능: 병렬적으로 작업을 수행하기 위해 별도의 서브에이전트들을 생성한다. `execute_code` 을 통한 프로그래밍 방식의 호출을 통해, 여러 단계로 구성된 처리 과정을 단 한 번의 추론 작업으로 통합할 수 있다.
- 오픈 스탠더드 기술 : agentskills.io와 호환된다. 이러한 기술들은 어디서나 사용할 수 있으며, 공유가 가능하다. 또한, Skills Hub를 통해 커뮤니티 구성원들이 직접 기술을 제공할 수도 있다.

### 기술 스택

- **아키텍처**: ReAct(Reasoning and Acting) 루프. 관찰 → 추론 → 행동을 반복합니다. 트랜스포트 추상화로 OpenAI 호환·Anthropic·Bedrock 등 여러 LLM 백엔드를 분리해 다루고, 게이트웨이는 플러그인 호스트로 작동합니다(12장 아키텍처 참고).
- **모델**: 특정 모델에 묶이지 않는 하네스 구조이다. 기본 채팅 모델은 설치 시 선택하며, 트랜스포트 추상화로 OpenAI 호환·Anthropic·로컬 모델 등을 바꿔 끼울 수 있습니다. NousResearch가 Atropos 강화학습 프레임워크로 도구 호출을 학습시킨 자체 Hermes 모델 계열도 그중 한 선택지입니다.
- **코드**: Python 91.4%. 나머지는 Shell, JavaScript(Ink TUI) 등.
- **라이선스**: MIT.
